# Soheil Nikzad — Personal Landing Page

نسخه‌ی اولیه‌ی لندینگ شخصی و رزومه‌ی آنلاین سهیل نیک‌زاد.

## اجرای محلی

هیچ نصب یا وابستگی‌ای لازم نیست. فایل `index.html` را مستقیماً در مرورگر باز کنید.

برای اجرای بهتر با یک وب‌سرور محلی:

```bash
python3 -m http.server 8080
```

سپس این آدرس را باز کنید:

```text
http://localhost:8080
```

## انتشار روی GitHub Pages

1. فایل‌ها را در یک ریپوی GitHub قرار دهید.
2. در Settings → Pages، بخش Source را روی GitHub Actions بگذارید.
3. Workflow موجود در `.github/workflows/deploy.yml` سایت را منتشر می‌کند.

## مواردی که باید در نسخه بعدی نهایی شوند

- تصویر پرتره
- ایمیل و لینک‌های تماس
- لینک LinkedIn و شبکه‌های حرفه‌ای
- تاریخ‌های دقیق مسیر حرفه‌ای
- متن نهایی هر پروژه و شواهد عمومی
- دامنه در فایل `CNAME`
- تصاویر Open Graph

## ساختار

- `index.html`: محتوا و ساختار صفحه
- `styles.css`: سیستم طراحی، واکنش‌گرایی و حالت چاپ
- `script.js`: فارسی/انگلیسی، پوسته روشن/تیره و تعامل‌ها
- `assets/`: فاوآیکون و تصویر موقت پرتره
- `.github/workflows/deploy.yml`: انتشار خودکار روی GitHub Pages
